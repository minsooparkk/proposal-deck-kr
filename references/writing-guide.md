# 문체와 수정 사례

한 서비스 소개서(해외 파견 직원 세무 서비스 예시)를 최초본부터 최종본까지 여러 차례 검수하며 도출한 기준이다. 수정 중 잠시 사용했다가 다시 바꾼 문구는 최종 예시와 구별한다. 세무 문구 예시는 문체·구성 학습용이며 현재 법령의 해석이나 특정 고객에 대한 결론으로 재사용하지 않는다.

## 제목·부제·본문의 역할

- 제목은 짧아도 주제가 분명하면 충분하다. `특성`, `업무 수행 방식`, `국가별 업무 범위`처럼 내용을 직접 드러낸다.
- 하위 페이지 제목은 섹션명과 진행 순서, 세부 주제로 구성한다. 예: `주재원 세무의 특성(1/2) - 양국 세법의 적용`.
- 새 장의 부제는 필요한 이유·조건·검토 방향을 한두 문장으로 설명하며, 목차·보수표 등 자체로 이해되는 장에 강제로 추가하지 않는다. 기존 문서의 헤드메시지·요약 설명문은 본문과 중복되더라도 요청 없이 삭제하지 않는다. 줄바꿈과 보존 기준은 [공통 편집 규칙](editing-rules.md)을 따른다.
- 본문의 짧은 항목명은 업무 개념을 드러내는 명사형으로, 설명은 자연스러운 전문 문장으로 쓴다.

## Before → After 예시

아래 사례는 이해를 위해 일부 문장을 요약했다.

| Before | After | 적용 기준 |
|---|---|---|
| 주재원 세무의 어려움 | 주재원 세무의 특성 | 구어적인 인상보다 검토할 주제 명시 |
| 주재원 세무는 두 나라의 규칙이 동시에 적용됩니다. | 주재원 세무의 특성(1/2) - 양국 세법의 적용 | 문장형 제목을 섹션·주제 체계로 정리 |
| 현지 세금과 한국 세금은 서로 맞물려 계산됩니다. | 한국과 파견국에서 각각 납세의무가 발생할 수 있으므로, 양국 세법과 조세조약을 함께 검토해야 합니다. | 모호한 관계 대신 조건과 검토 필요성 설명 |
| 나뉘어 지급되는 급여 | 국내외 급여의 합산 신고 | 풀어 쓴 상황을 검토 업무로 명확화 |
| 공제 대상 세금인지, 한도 안인지, 사회보험료와 구분되는지 봐야 합니다. | 현지 납부세액의 공제 대상 여부와 공제한도를 검토하고, 소득세와 사회보험료를 구분하여 공제 가능액을 확인해야 합니다. | 구어체를 구체적인 검토 대상으로 교정 |
| 급여·수당에 따라 합계 세금과 실수령액이 달라집니다. | 양국의 세부담과 주재원의 실수령액을 함께 고려한 급여·수당 설계가 필요합니다. | 현상 설명을 검토·설계 필요성으로 연결 |
| ○○의 해결 방식 | 업무 수행 방식 | 추상적인 홍보 표현보다 실제 업무를 명명 |
| 한국 신고와 현지 신고를 같은 숫자로 맞춥니다. | 금액·환율·귀속연도별 신고자료를 대사하여 차이와 조정사항을 정리할 예정입니다. | 수치를 억지로 일치시키는 인상을 피하고 실제 업무 설명 |
| 주요 문의사항 | 사전 세무 자문 | 질문 목록이 아니라 제공 업무에 맞는 제목 사용 |
| 서울 11곳 | 서울 11개소 | 사무소 단위 통일, 숫자는 유지 |

중간 수정안의 `일반적인 서비스와 한계`, `주요 검토 공백`, `발생 가능한 위험`, `○○의 수행 체계`도 사용자가 어색하다고 지적했다. 최종 방향은 각각 `신고 중심 세무서비스의 한계`, `검토상 한계`, `세무상 영향`, `업무 수행 방식`이다. 낱말을 일괄 치환하기보다 해당 표·페이지가 실제로 설명하는 내용을 기준으로 고른다.

## 서술 시제와 구체성

| 문장의 역할 | 자연스러운 서술 |
|---|---|
| 세무 특성·검토 필요성 | 사실관계에 따라 검토가 필요합니다. |
| 제안하는 수행 업무 | 의뢰 시점과 협의한 범위에 따라 검토할 예정입니다. |
| 확정된 사실·금액·범위 | 기준일 현재 ○○입니다. / 보수는 ○○원입니다. |

`~할 예정입니다`를 모든 문장에 기계적으로 붙이지 않는다. 수행 주체, 검토 대상, 시점, 전달 내용을 문맥상 필요한 만큼 밝힌다. 모든 항목에 네 요소를 채우는 고정 문장 틀로 만들지 않는다. 계약 전제나 제외업무도 필요한 곳에 한 번 명확히 쓰고 매 문장에 반복하지 않는다.

## 검토 과제를 수행 계획으로 바꾸는 예

- Before: 양도 시점별 세부담과 특례 요건을 검토해야 합니다.
- After: 양도 전에 출국 전후 양도 시점별 세부담과 비과세 특례 요건을 비교·검토할 예정입니다.
- 이유: 서비스 설명에서는 필요성뿐 아니라 검토 시점과 제공할 업무가 보여야 한다. 실제 수임 시점과 약정 범위가 이를 뒷받침하는 경우에 사용한다.

## 재사용할 원칙과 적용 예

| 재사용할 원칙 | 적용 예 |
|---|---|
| 표지는 주제가 명확하면 간결하게 구성 | 표지 부제를 줄이고 표지 다음에 목차 배치 |
| 같은 역할의 요소는 같은 규격으로 | 표지·간지의 제목, 법인명, 로고 규격 통일 |
| 단계명·짧은 대상 문구는 영역 안에서 정렬 | 단계 제목과 대상 고객 설명 가운데 정렬 |
| 의미 단위로 줄바꿈하고 단어 분리 방지 | `검/토` 대신 Shift+Enter에 해당하는 수동 줄바꿈 |
| 협업 역할과 국가별 범위를 분리 | 작성 법인·협업 전문가의 2개 영역 도식과 별도 국가별 범위표 |
| 페이지 목적에 필요하지 않은 보조정보는 생략 | 업무 절차 장의 웹사이트·이메일 강조를 낮추거나 삭제 |
| 경력과 실적의 주체를 정확히 씀 | `담당 회계사 주요 수행 경험`으로 표기, 고객사 실명 미추가 |

한 문서에서 정한 국가 순서, 표지 부제 삭제, 페이지 수, 특정 항목의 한 줄 배치, 리뷰 단위를 모든 제안서의 고정 규칙으로 만들지 않는다. 필요하면 문맥과 사용자의 요청에 따라 바꾼다.

최종 검수에서 사용자가 직접 삭제한 요소(예: 업무 절차 장의 웹사이트·이메일)는 이후 편집 시 다시 삽입하지 않는다. 이 결정은 해당 페이지에 한정되며 다른 페이지나 모든 제안서에서 연락처를 없애는 규칙으로 확대하지 않는다. 사용자가 직접 수정한 PPT가 전달되지 않았다면, 결정의 기록과 실제 파일 반영 여부를 구분한다.

사용자가 명시적으로 삭제를 요청한 경력 주석(예: `※ 이전 소속 법인 재직 시 수행 경험 포함`)은 같은 문서를 수정할 때 자동으로 되살리지 않는다. 이 결정은 과거 소속에서의 경험을 현 소속 법인의 수임 실적으로 바꾸거나 모든 문서에서 경력의 주체를 생략하라는 뜻이 아니다.

## 변경 요약

페이지별 세부 수정 기록과 메일용 요약을 구분한다. 메일에서는 `문체·제목`, `구성`, `문제와 수행 업무의 연결`, `협업·범위`, `가독성` 등 큰 변화로 묶는다. 중간 버전에서 추가했다가 최종적으로 삭제한 요소를 최초본 대비 신규 변화로 적지 않는다. 상대방의 초안을 평가하는 표현보다 무엇을 어떻게 정리했는지 담백하게 설명한다.
