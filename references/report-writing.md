# 보고서 구성과 문체

## 기본 흐름

| 구간 | 독자가 얻어야 할 답 |
|---|---|
| 표지·목차 | 누구의 어떤 의사결정을 위한 보고서인지, 어디에 답이 있는지 |
| Executive Summary 간지·핵심 요약 | 본문 판단을 바탕으로 이번 결론과 우선 조치 |
| 검토 개요 | 대상 사업체·관계, 자료 기간과 기준일, 합의한 검토 범위 |
| 장별 본문 | 질문별 발견사항과 근거, 계산, 해석, 조건부 제언 |
| 종합 제언 | 중요도와 실행 가능성을 고려한 우선순위, 다음 조치 |
| 필요한 별도 근거 자료 | 상세 산식·가정·자료 위치·법령 근거 등 재검토 가능한 내용 |

정식 보고서는 `표지 → 목차 → Executive Summary 간지·핵심 요약 → 장별 간지·본문 → 실행 과제 → 마무리`를 기본으로 한다. 요약은 본문 판단을 정리한 뒤 작성한다. 부록은 필요한 경우에만 넣고 상세 근거·검산·내부 이력은 별도 기록으로 보존한다. 요약 메모나 일부 페이지 수정은 요청 범위를 따른다. 고정 분량을 강제하거나 법인 소개·보수를 자동으로 붙이지 않는다. [사용자 검토 스타일](user-reviewed-style.md)의 표·숫자·각주 기준을 함께 적용한다.

위 구간은 문서의 큰 틀이다. 본문을 자료 종류별로 나열하거나 모든 업무를 같은 순서에 끼워 맞추지 않는다. [페이지 흐름 설계](report-flow.md)에 따라 페이지별 핵심 메시지와 먼저 알아야 할 내용을 정하고, 본문을 순서대로 읽어 이해할 수 있게 배치한다. 핵심 요약에서 판단을 먼저 제시하는 것과, 본문 분석에 필요한 전제를 뒤쪽에 미루는 것을 구별한다.

## 요청에 답하는 본문

먼저 고객의 요청마다 다음 연결이 성립하는지 확인한다. 이 표를 항상 보고서에 넣으라는 뜻은 아니다.

| 연결 | 작성 내용 |
|---|---|
| 질문 | 고객이 비교하거나 결정하려는 사항 |
| 현재 판단 | 보유자료로 말할 수 있는 결론 또는 잠정 판단 |
| 근거 | 자료의 수치·기간·범위, 계산 또는 적용 규정 |
| 한계 | 실제 결론을 바꿀 수 있는 미확인 사실·가정 |
| 후속 조치 | 누가 어떤 자료·검토를 통해 무엇을 확정할지 |

`추가 자료가 필요하다`는 말만 반복하지 않는다. 현재 자료로 가능한 분석을 제시하고, 누락된 정보가 어느 판단에 어떤 영향을 주는지 설명한다. 실행을 확정할 근거가 부족하면 비교 기준과 조건부 대안을 제시한다.

## 판단과 근거가 연결되는 페이지

- 분석 본문의 제목 아래에는 해당 고객에 대한 핵심 판단과 중요한 조건을 완결된 한 문장으로 적는 것을 기본으로 한다. 필요한 경우 두 문장으로 나누되 불필요한 설명을 늘리지 않는다. 자료가 부족하면 판단 가능한 범위와 남은 쟁점을 밝힌다. 자료 목록·부록·절차 안내에는 억지로 분석 결론을 만들지 않는다.
- 요건 검토는 `판단 기준 → 회사의 사실·증빙 → 충족 여부와 이유`가 같은 행이나 열에서 이어지게 한다. 기준과 회사 적용 결과가 서로 다른 페이지에 흩어져 대조하기 어렵게 만들지 않는다.
- 대안 비교는 공통 전제와 대안의 정의를 먼저 설명한다. 비교표는 같은 기간·단위·대상 범위를 사용하고, 비교표 뒤의 해설은 실제 차이가 발생한 항목을 짚는다.
- 항목이 많으면 전체 결과를 먼저 보여준 뒤 중요한 변화·예외와 그 이유를 설명한다. 자료에서 확인하지 못한 원인은 가설이나 추가 확인 사항으로 표시한다.
- 종합 제언은 본문에서 확인한 결과를 받아 작성한다. 권고안에 필요한 새로운 판단 기준이나 중요한 조건을 마지막 페이지에서 처음 소개하지 않는다.

## 사실·분석·제언의 구분

- **확인 사실:** 특정 자료와 기준일에서 확인한 범위만 기술한다. 엑셀 파일의 귀속 회사가 불명확하면 이를 확인 전제로 표시한다.
- **전달사항:** 면담이나 사용자가 전한 이력은 원증빙 확인 사실과 구분한다. 전달자의 추측을 사실로 바꾸지 않는다.
- **계산·분석:** 원자료, 단위, 식과 해석을 연결한다. 산술적 분해나 두 항목의 동시 변화를 실제 인과관계로 단정하지 않는다.
- **시나리오:** 공통 기준과 각 시나리오의 차이를 분리한다. 평가일·이전 지분·재산 범위 등이 달라진 계산을 동등 비교처럼 제시하지 않는다.
- **제언:** 고객의 상황과 분석 결과에 근거하여 효과·조건·실행 비용을 설명한다. 전문 범위 밖의 경영 처방이나 성과 보장을 추가하지 않는다.

## 재무·세무 보고서의 계산 전제

- 화폐 단위, 기간, 개인과 법인의 자산 귀속을 일관되게 표시한다. 표·차트 단위는 [공통 편집 규칙](editing-rules.md)에 따라 우측 상단에 단위만 표시하며, 반올림 전 원자료와 계산 기준은 검산 자료에 보존한다. 관계회사·개인의 지분과 회사 자산을 중복 합산하지 않는다.
- 회계상 이익·장부가액을 세법상 이익·평가액의 대용치로 사용했다면 예비 계산임을 본문에 표시한다. 확정된 법정 평가로 설명하지 않는다.
- 예상세액은 포함한 재산·과거 증여·채무·공제·특례 요건·신고세액공제의 범위를 밝힌다. 핵심 공제 요건을 가정했으면 표나 금액 가까이에 표시한다.
- 기존에 신고한 공제·감면과 신규 발굴 가능 항목을 구분한다. 신고서에 기재되었다는 이유로 적법성 검토까지 끝났다고 주장하지 않는다.
- 법령은 현행 규정, 개정안, 시행일·적용시기를 구분한다. 과거 사례를 현재 계산에 적용할 때 해당 시점의 법령 차이를 확인한다.
- 파일 작성일, 자료 기준일, 법령 확인일을 혼동하지 않는다. 서식 수정만으로 법령과 사실을 재검증했다고 표시하지 않는다.
- 설명용 예시 숫자는 실제 고객의 적용 가능 금액과 구분한다. 이 스킬이나 원본의 수치·기간을 새 보고서에 기본값으로 넣지 않는다.

## 제목과 문장

- 제목 예: `○○주식회사 재무·세무 진단 보고서`, `가업승계 방안 및 예상세액 검토 보고서`.
- 내용 장 예: `가업승계 검토(1/3) - 비상장주식 가치의 예비 평가`. 장명·간지·목차는 같은 용어로 맞춘다.
- 확인 결과에는 `제공된 20XX년 신고자료에서 ○○를 확인했습니다`, 잠정 판단에는 `현재 자료에 기초한 예비 추정치입니다`처럼 근거와 확정 수준이 드러나는 문장을 쓴다.
- `봐야 합니다`, `어쩌구`, `좋아 보입니다` 대신 검토 대상과 이유를 명시한다. 추상적인 명사나 어려운 말만 늘리지 않는다.
- 보고 결과를 모두 미래형으로 쓰지 않는다. 이미 수행한 검토, 앞으로 필요한 확인, 제안하는 후속 업무를 구분한다.

## 범위와 후속 검토

재무현황 설명만 합의한 경우에는 매출·수익성·자산 변동과 면담 질문을 제시하고, 운영 개선 처방은 추가 범위 협의 후 다룬다. 다른 고객에게도 재무분석을 무조건 2장으로 제한하지는 않는다. 의사결정을 위해 필요한 추가 자료는 목적별로 정리하며, 이미 받은 자료를 다시 요청하지 않는다.
