# 원형 슬라이드 재사용 안내

두 원형은 실제 검수를 거친 문서에서 고객·법인 정보, 금액, 날짜, 인물, 발표자 노트, 문서 속성을 지우고 자리표시(`[장명]`, `[항목]`, `○○회계법인` 등)로 바꾼 틀이다. 디자인·배치·글꼴은 그대로다. 차트 자료와 수치는 모두 자리표시 값이다.

## 새 보고서 기본 틀 — report-template.pptx

아래 유형을 필요한 만큼 복제하며, 9쪽을 납품 분량으로 고정하지 않는다. 미리보기: `assets/report-template-preview.png`, 전체 장: `assets/report-template-layouts.png`.

| 틀 쪽 | 유형 | 유지할 요소 |
|---|---|---|
| 1 | 표지 | 로고·청색 배경·공식 제목·작성일 |
| 2 | 목차 | 장명·번호·실제 쪽수 연결 |
| 3 | Executive Summary 간지 | 큰 청색 표제 하나, 두 줄·ES 약자 없음 |
| 4 | 핵심 요약 | 주제와 판단·권고의 2열 표, 긴 각주 없음 |
| 5 | 장 간지 | 청색 번호·흰색 장명 |
| 6 | 요건·판단 | 짧은 구절, 가운데 정렬의 3열 표 |
| 7 | 계산 근거 | 단계·산식·결과, 최종 행 강조, 옅은 파란 결론 띠 |
| 8 | 실행 과제 | 주제·자료·결정사항의 3열 표 |
| 9 | 마무리 | Thank You·감사 문구 |

사용자 파일을 계속 수정할 때는 이 중립 틀로 갈아엎지 않고 사용자 최신 파일 자체를 시작점으로 한다. 중립 틀은 새 보고서용이다. 색·폰트·자리수·각주 기준은 [사용자 검토 스타일](user-reviewed-style.md)을 따른다. 7쪽 표 머리글 안의 `(단위: 억원)`은 단위 기준([공통 편집 규칙](editing-rules.md))보다 먼저 만든 배치이므로, 공통 단위면 표 우측 상단으로 옮긴다.

## 확정된 원형과 내용의 분리

- 사용자가 최종본에서 삭제한 요소(예: 업무 절차 장의 웹사이트·이메일, 경력 주석)를 예전 빌더나 이전 버전에서 되살리지 않는다. 이는 해당 문서의 결정이며, 모든 문서에서 연락처나 경력 주석을 금지한다는 뜻은 아니다.
- 원형의 주제·자리표시 값은 디자인 설명용이다. 새 문서의 현재 고객 상황으로 검증 없이 이월하지 않는다.
- 미리보기 그림은 원형을 그린 것이며, 이 스킬로 만든 새 문서의 예시 산출물이 아니다.

## 제작 방식

원형 전체를 사본으로 가져온 후 필요한 장 유형을 선택·복제하고 내용에 맞춰 조정한다. 현재 환경의 프레젠테이션 도구가 지원하는 가져오기·수정 경로를 사용한다. 특정 Python 빌더나 이전 생성 코드를 필수로 요구하지 않는다. 한 장을 통째로 래스터 이미지로 바꾸어 표·차트·문자 편집성을 없애지 않는다.
