# 법인 사실 자료 (채워 쓰는 틀)

제안서·소개서에 법인 현황·담당자·연락처를 넣을 때 읽는다. 이 파일을 복사해 `references/firm-facts.md` 로 두고 채운다. 비어 있는 칸은 문서에 쓰지 않고 `[확인 필요]` 로 남긴다. 숫자는 슬라이드에 쓰는 값을 `assets/firm.json` 의 `profile` 에도 같이 넣는다.

## 기준과 출처

| 칸 | 적을 것 | 가져올 곳 |
|---|---|---|
| 기준일 | 자료가 가리키는 결산일·조회일 | 원 자료의 표지·공시일 |
| 출처 | 자료명, 공시 접수번호 또는 주소, 조회일 | 회계법인 사업보고서(전자공시), 법인 홈페이지, 내부 확정 자료 |
| 확인자·확인일 | 누가 언제 원문과 대조했는지 | — |

수치마다 위 출처 중 하나를 붙인다. 홈페이지 홍보 문구와 공시 수치가 다르면 공시 기준을 쓰고 차이를 이 파일에 적는다. 서식만 고친 작업을 사실 재검증으로 표시하지 않는다.

## 담당자

| 칸 | 적을 것 |
|---|---|
| 이름·직함·자격 | 본인이 확인한 표기 |
| 약력 | 본인이 준 것만. 연차 표기 여부도 본인 결정에 따른다 |
| 대표 수행업무 | 이전 소속에서의 경험이면 그 사실을 구분할지 본인과 정한다 |
| 사진 | 공개 동의를 받은 파일 경로(`assets/firm.json` 의 `people[].photo`) |

법인 전체 실적과 담당자 개인 경력을 구분한다. 확인되지 않은 약력은 지어내지 않는다.
