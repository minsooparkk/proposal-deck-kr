# 구성과 논리

## 서비스 소개서의 기본 흐름

| 구간 | 독자가 알아야 할 내용 | 주재원 소개서의 적용 예 |
|---|---|---|
| 표지·목차 | 누구를 위한 어떤 자료인지, 전체 구성 | 주재원 세무 서비스 소개 / 표지 다음 목차 |
| 업무의 특성 | 왜 검토가 필요한지, 어떤 상황·단계에서 문제가 생기는지 | 양국 세법 적용 / 파견 단계별 세무 검토 |
| 기존 업무 범위와 한계 | 특정 범위로 수행할 때 추가 확인이 필요한 내용과 영향 | 신고 중심 세무서비스의 한계 |
| 업무 수행 방식 | 앞의 검토 과제에 대한 실제 제공 업무와 역할 | 국제조세 전문성 / 양국 신고 연계 / 국가별 범위 / 제공 서비스 / 사전 자문 |
| 담당자·업무 절차 | 누구와 어떤 절차로 진행하는지 | 담당 회계사 / 업무 진행 절차·연락처 |
| 법인 소개·마무리 | 수행 역량을 뒷받침하는 관련 사실 | 기준일이 있는 법인 현황 / 마무리 |

이는 서비스 소개서의 기본안이다. 짧은 제안서, 회사 소개서, 입찰양식에는 필요한 부분만 적용한다. 표지 부제·목차·간지·법인 소개 장 수·보수 유무는 문서 목적과 사용자의 요청에 맞춘다. 고객의 과제와 무관한 법인 소개를 분량 채우기용으로 늘리지 않는다.

## 소개서의 수임 목적

최종적으로 고객으로부터 수임하려는 업무가 무엇인지 대화에서 확인한 목적을 따른다. 예를 들어 관리체계 구축을 기장·신고 수임으로 연결하려는 소개서라면, 구축한 기준이 장부 반영·정기 검토·신고로 이어지는 구체적인 업무를 설명한다. 사용자가 선택하지 않은 일회성 구축·기존 대리인 유지 등을 외부 피드백만으로 중심 이용 방식으로 바꾸지 않는다. 특정 제안서의 수임 방식은 모든 서비스의 고정 조건으로 만들지 않으며 실제 약정 범위를 과장하지 않는다.

## 과업·보수 제안서의 흐름

정산검토 등 범위와 산출물이 정해진 용역에서는 `과업의 이해 → 수행 계획 및 보수 → 법인·수행 역량 소개`처럼 구성할 수 있다. 수행 절차·일정·품질관리·산출물·인력·보수를 필요한 만큼 연결하고, 관련 경험은 법인 소개와 함께 배치한다. 긴 제안서는 목차와 장 간지를 활용하되 모든 제안서에 세 장 구성이나 고정 페이지 수를 강제하지 않는다. 서비스 소개서에 보수 장을 자동 추가하지 않는다.

## 문제 제기와 수행 내용의 대응

2장에서 검토상 한계를 제시했다면 3장에서 대응되는 업무가 보이는지 확인한다. 작성 중 다음 표를 내부 검토용으로 쓰되 고객용 슬라이드에 별도 표를 반드시 추가할 필요는 없다.

| 검토상 한계 | 구체적인 수행 내용 | 연결이 성립하는 이유 |
|---|---|---|
| 양국 신고자료 대사 미흡 | 금액·환율·귀속연도별 신고자료를 대사하여 차이·조정사항 정리 | 비교 대상과 전달 내용이 드러남 |
| 국가별 검토 결과 공유 부족 | 작성 법인이 현지 전문가의 검토 결과를 취합하고 신고 반영사항 협의 | 전문가 사이의 조율 주체가 드러남 |
| 국내 세법 위주의 검토 | 양국 거주자 판정 결과와 조세조약에 따른 과세 범위·세액공제 검토 | 국내·현지 검토 결과를 함께 다루는 업무가 드러남 |
| 급여·양도·증여의 사전 검토 부족 | 파견 전 급여 구조 검토, 양도·증여 실행 전 시점별 세부담 비교 | 신고 이후가 아닌 의사결정 전 검토 시점이 드러남 |

위 표는 주재원 사례다. 다른 서비스에는 해당 고객의 실제 검토 과제와 약정할 업무로 새로 작성한다.

대응이 약한 경우 먼저 기존 서비스 설명의 주체·대상·시점·전달 내용을 명확히 한다. 범위 밖 업무를 새로 약속하거나 `통합 관리`, `원스톱`, `풍부한 경험` 같은 표현만 더하지 않는다. 실제 대응할 수 없는 항목은 별도 협의·외부 전문가 확인으로 범위를 구분한다.

## 역할 도식과 지원 범위

- 협업 구조는 역할로 설명한다. 예: 왼쪽 `○○회계법인`(작성 법인), 오른쪽 `현지 회계·세무 전문가`, 사이에 `자료·검토 결과 공유 및 협의`.
- 국가별 가능 업무는 별도 범위표로 정리한다. 국가별 설명과 일반 협업 도식을 반복하지 않는다.
- 범용 도식을 쓴다고 모든 국가에서 같은 서비스가 가능한 것은 아니다. 본문·도식·범위표에서 실제 범위를 일치시킨다.
- `제휴 확대 중`은 현재 진행 사실을 사용자가 확인한 경우만 쓴다. 지원 가능 국가를 임의로 늘리지 않는다.
- 사실 설명과 수행 약속을 구별한다. 법인·회계사 경력은 업무 수행 계획을 뒷받침하는 정보이며 업무 자체의 설명을 대체하지 않는다.

## 표현과 사실의 범위

`대부분의 다른 업체는 못 한다`처럼 업계 전체를 단정하지 않는다. 다른 법인을 비방하거나 비교 광고로 읽힐 표현을 쓰지 않는다(공인회계사·세무사의 광고 관련 규정). 대신 고객이 스스로 확인할 질문이나 '일반적인 서비스'의 구조적 한계로 쓴다. `국내 신고 중심으로 업무를 수행하는 경우`처럼 비교 대상을 특정한다. 작은 현재 고객 수를 유리한 다른 숫자로 대체하거나 법인 전체 실적을 담당자 개인 실적으로 표현하지 않는다.

병의원 등 다른 고객군에서는 `대출 심사용 재무자료`, `의료법·세무상 검토를 거친 구조 설계`, `관련 자격 전문가 연계`처럼 실제 업무를 설명한다. `리스크 없는 구조` 등 결과 보장은 피한다. 업종에 따라 오해를 부르는 말도 피한다(예: 병의원 소개서에서 `사무장`은 사무장병원으로 읽힐 수 있다). 기관명과 법령상 기준은 쓰는 시점에 확인한다.

## 독립성 확인 (회계검증·정산검토·감사 성격의 제안서)

발주처가 "발주처의 외부감사인(또는 감사)과 다른 별도 회계법인"을 요구하는 과업은 제안서에 독립성 문구가 들어간다. 확인 없이 쓰지 않는다.

1. 발주처 감사보고서를 구한다: 발주처 홈페이지의 재정·경영 공시 메뉴, 공익법인 결산서류 공시, 전자공시(외부감사 대상 법인). 재무제표 감사보고서와 기부금 등 별도 감사보고서가 있으면 모두 본다.
2. 보고서 말미 감사인 서명란(회계법인명·대표자)을 확인한다. PDF는 텍스트를 뽑아 "회계법인"이 든 줄을 찾으면 빠르다.
3. 공개 보고서는 보통 직전 연도 것이므로, 대상 연도 감사인이 바뀌었는지와 작성 법인 소속 회계사가 발주처의 감사(監事)를 겸하는지는 별도 확인 항목으로 남긴다.
4. 본문에는 상대 법인명을 쓰지 않고 "외부감사인과 다른 별도 회계법인"으로 쓴다. 확인한 보고서명·연도·감사인과 근거 지침은 발표자 노트에 남긴다. 고객에게 파일을 그대로 보내는 경우에는 노트 대신 별도 근거 기록에 둔다.
